## GUI开发经验 (已更新)
- **GUI框架选择**: 使用PyQt5创建桌面应用界面
- **架构设计**: 采用三层架构
  - GUI层: `patchcore_gui.py` + `inference_gui.py` - 负责用户界面和交互
  - 逻辑层: `patchcore_trainer.py` + `inference_engine.py` - 封装业务逻辑，提供回调接口
  - 后端: `flexible_patchcore_train.py` - 实际的训练和推理实现
- **线程处理**: 使用QThread防止GUI界面在长时间操作时卡顿
- **配置管理**: 支持JSON格式的配置保存和加载
- **路径处理**: 提供文件夹浏览对话框，支持相对和绝对路径
- **字体优化**: 统一设置合适的字体大小，提升用户体验
- **进度跟踪**: 详细的阶段进度显示，包含时间估计和百分比
- **推理功能**: 完整的推理工具，支持单图和批量检测
- **可视化展示**: 集成matplotlib生成异常热力图和叠加图像
- **双GUI架构**: 训练GUI和推理GUI完全独立，各司其职

## 后续使用指南

### 替换数据集的标准流程 (已更新)
1. 将新数据放入指定位置：
   - 正常样本 → `C:\Users\Administrator\Desktop\自监督测试\ALL_OK`
   - 异常样本 → `C:\Users\Administrator\Desktop\自监督测试\ALL_NG`
2. 运行 `python reorganize_data.py`
3. 使用GUI工具进行训练：
   - 双击 `gui/start_gui.bat`
   - 或运行 `python train_custom_data.py`
4. 运行 `python inference_custom_data.py` (选择测试模式)

### GUI使用流程 (已更新)
1. **启动**: 双击 `gui/start_gui.bat` 或运行 `python gui/run_gui.py`
2. **配置**: 使用图形界面设置所有训练参数
3. **验证**: 点击"检查数据"确认配置正确
4. **训练**: 点击"开始训练"启动训练流程
5. **保存**: 可选择保存配置为JSON文件供下次使用
6. **推理**: 使用新的推理界面进行单图或批量预测 (待开发)

### 数据重组脚本功能
- 自动检测和转换图像格式
- 智能7:3分割正常样本用于训练和测试
- 创建全量测试目录支持完整评估
- 提供详细的统计信息和处理日志

### 更换模型的标准流程
1. 修改 `train_custom_data.py` 中的模型导入和初始化
2. 根据新模型调整训练参数（epochs, batch_size等）
3. 同步修改 `inference_custom_data.py` 中的模型加载
4. 更新模型权重文件路径
5. 重新训练和测试
6. 如需要，更新GUI中的模型选项

### 推荐的模型选择
- **实时检测**: EfficientAd, FastFlow
- **高精度分析**: Patchcore, PaDiM  
- **研究实验**: Reverse Distillation
- **资源受限**: EfficientAd (small)
