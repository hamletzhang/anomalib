# PatchCore 推理GUI使用说明

## 📖 概述

PatchCore推理GUI是一个独立的图形界面工具，用于对训练好的PatchCore模型进行异常检测推理。支持单图片预测和批量文件夹预测，并提供可视化结果展示。

## 🚀 快速启动

### 方法一：批处理启动 (推荐)
```bash
# 双击运行
start_inference_gui.bat
```

### 方法二：Python启动
```bash
# 确保在gui目录下
cd gui

# 激活conda环境
conda activate anomalib

# 启动推理界面
python run_inference_gui.py
```

### 方法三：直接启动
```bash
python inference_gui.py
```

## 🖥️ 界面介绍

推理GUI采用左右分栏设计：
- **左侧控制面板**: 模型配置、推理设置、操作控制
- **右侧显示面板**: 推理结果展示和日志信息

### 控制面板功能

#### 1. 模型配置
- **模型路径**: 自动查找最新训练的模型或手动选择.ckpt文件
- **配置文件**: 可选择对应的JSON配置文件，或使用默认配置
- **加载模型**: 点击加载模型到内存

#### 2. 推理配置
- **异常阈值**: 设置异常检测阈值 (0.0-1.0)，默认0.5

#### 3. 单图推理
- **图片路径**: 选择要检测的单张图片
- **开始推理**: 对选中图片进行异常检测

#### 4. 批量推理
- **输入文件夹**: 选择包含多张图片的文件夹
- **输出文件夹**: 指定保存推理结果的目录
- **开始批量推理**: 对文件夹中所有图片进行检测

#### 5. 操作控制
- **进度条**: 显示批量推理进度
- **停止推理**: 中断正在进行的推理
- **清除结果**: 清空当前显示的结果

### 显示面板功能

#### 推理结果标签页
- **图片显示区**: 显示原始图片和推理结果
- **结果信息**: 显示详细的检测结果
  - 异常分数
  - 预测结果（正常/异常）
  - 图片尺寸等信息

#### 日志信息标签页
- **详细日志**: 显示推理过程的详细信息
- **时间戳**: 每条日志都有时间标记
- **清除日志**: 清空日志内容

## 📊 使用流程

### 单图推理流程
1. **启动应用** → 双击`start_inference_gui.bat`
2. **自动加载模型** → 应用会自动查找最新训练的模型
3. **手动加载（可选）** → 如需使用特定模型，点击"浏览"选择
4. **点击"加载模型"** → 将模型加载到内存
5. **选择图片** → 点击"选择图片"，选择要检测的图片
6. **调整阈值（可选）** → 根据需要调整异常检测阈值
7. **开始推理** → 点击"开始推理"按钮
8. **查看结果** → 在右侧查看检测结果

### 批量推理流程
1. **启动应用** → 双击`start_inference_gui.bat`
2. **加载模型** → 同上
3. **选择输入文件夹** → 包含待检测图片的文件夹
4. **设置输出文件夹** → 推理结果保存位置
5. **调整阈值（可选）** → 根据需要调整异常检测阈值
6. **开始批量推理** → 点击"开始批量推理"
7. **监控进度** → 观察进度条和日志信息
8. **查看结果** → 推理完成后查看统计结果

## 📁 输出结果说明

### 单图推理结果
- **图片显示**: 在界面中直接显示原始图片
- **结果信息**: 包含异常分数、预测结果等详细信息

### 批量推理结果
推理完成后会在输出文件夹中生成：

#### 可视化图片
- `{图片名}_result.png`: 包含三部分的可视化结果
  - **原始图片**: 输入的原始图像
  - **异常热力图**: 显示异常区域的热力图
  - **叠加结果**: 原图与热力图的叠加显示

#### 结果摘要
- `inference_summary.json`: 包含完整的推理统计信息
```json

  "detailed_results": [...]
```

## ⚙️ 配置说明

### 支持的图片格式
- PNG (.png)
- JPEG (.jpg, .jpeg)
- BMP (.bmp)
- TIFF (.tiff, .tif)

### 阈值设置建议
- **0.3-0.4**: 较敏感，可能有更多误报
- **0.5**: 平衡设置（默认）
- **0.6-0.7**: 较严格，减少误报但可能漏检

### 性能优化
- **GPU加速**: 如有NVIDIA GPU且安装CUDA，会自动使用GPU加速
- **批量大小**: 大批量处理时建议监控内存使用情况
- **图片尺寸**: 大尺寸图片会自动调整，但可能影响检测精度

## 🔧 故障排除

### 常见问题

#### 1. 模型加载失败
**问题**: 提示"模型加载失败"
**解决方案**:
- 确保已训练过模型（存在results目录）
- 检查模型文件是否完整（.ckpt文件）
- 确认配置文件格式正确

#### 2. 图片无法加载
**问题**: 选择图片后无法显示
**解决方案**:
- 检查图片格式是否支持
- 确认图片文件没有损坏
- 尝试使用其他图片测试

#### 3. 推理速度慢
**问题**: 推理过程很慢
**解决方案**:
- 检查是否使用GPU加速
- 确认CUDA环境正确安装
- 降低图片分辨率

#### 4. 内存不足
**问题**: 大批量推理时内存溢出
**解决方案**:
- 分批处理图片
- 降低图片分辨率
- 关闭其他占用内存的程序

### 依赖问题

如果启动时提示缺少依赖，请安装：
```bash
# 基础依赖
conda activate anomalib
pip install PyQt5 opencv-python matplotlib Pillow

# 如果anomalib未安装
pip install anomalib
```

## 🚀 使用技巧

### 1. 快速检测
- 使用默认配置可快速开始检测
- 首次使用建议先测试单张图片

### 2. 批量处理
- 大量图片建议分批处理
- 可通过输出文件夹组织不同批次的结果

### 3. 结果分析
- 关注异常分数分布
- 结合可视化图片分析检测效果
- 根据实际情况调整阈值

### 4. 性能优化
- 确保使用GPU加速
- 合理设置检测阈值
- 监控系统资源使用情况

## 📞 技术支持

如遇到问题，请检查：
1. 日志信息中的错误提示
2. 是否正确安装所有依赖
3. 模型文件是否完整
4. 输入数据格式是否正确

推理GUI与训练GUI完全独立，可以单独使用。确保先通过训练GUI完成模型训练，再使用推理GUI进行检测。
